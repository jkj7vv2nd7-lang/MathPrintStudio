# MathPrint Studio 1.3.1

## 実利用・改善フェーズ公開ベース

MathPrint Studio は、教師が数学教材を「探す・作る・使う・気づく・育てる」ためのブラウザ型教材開発環境です。

1.3.1 は、第5世代の機能を大きく増やす版ではなく、**実際の先生の利用を前提に、使い始めやすさ・不具合報告・自己診断・改善記録を強化した公開ベース**です。

## 主な機能

- 数式・図形・グラフを含む教材編集
- 教材ライブラリ、教材ビルダー、教材セット
- 生徒版・教師版・模範解答版
- 教材資産センター
- 教材の改訂・バージョン管理・差分確認
- 教材の系列・次年度継承
- 教材カルテ、使用状況、気づき記録
- 教材テンプレート
- 長期運用センター、バックアップ、復元基盤
- 実利用・改善センター
- 公開版セルフチェック
- サポート情報のJSON出力
- 小学校・中学校・高等学校・大学の利用プロフィール

## 起動方法

`index.html` をChrome / Edgeなどの最新ブラウザで開いてください。

サーバーを必要としない構成を基本としています。GitHub Pagesなどの静的ホスティングにも配置できます。

## データについて

教材データは原則として利用者のブラウザ内に保存されます。重要な教材は定期的にバックアップJSONを保存してください。

実在する児童生徒の氏名・住所・成績など、公開や共有に不適切な個人情報を教材データに入力しないでください。

## 実利用フェーズについて

この版の完成条件は「機能を増やし続けること」ではありません。

実際の授業・教材研究で使用し、

- 分かりにくい
- 便利だった
- エラーが出た
- こうなっていると助かる

という記録を集め、同じ問題が繰り返し確認された箇所から修正します。

AI等による自動判断を教材・授業の最終決定に用いる設計ではありません。教師が確認して判断することを基本とします。

## 既知の限界

構文・HTML構造・内部自己診断は確認していますが、すべてのブラウザ、すべての画面操作、すべてのWord/PPTX環境での完全な動作を自動保証するものではありません。

公開後は実機での利用結果を優先して改善します。
